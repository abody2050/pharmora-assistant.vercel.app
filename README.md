# فارمورا المساعد

موقع ثابت (index.html) + دالة خادم واحدة (api/scan.js) تقرأ صور الأدوية عبر Google Gemini.

## النشر على Vercel
1. ارفع هذا المجلد كمشروع جديد.
2. Settings ← Environment Variables، أضف:
   - `GEMINI_API_KEY` = مفتاحك (مطلوب). لا تضعه داخل أي ملف ولا في الموقع نفسه.
   - `GEMINI_MODEL` (اختياري، النموذج السريع للمحاولة الأولى، الافتراضي gemini-2.5-flash-lite) و`GEMINI_STRONG` (الافتراضي gemini-2.5-flash، يُستخدم عندما تكون القراءة الأولى ضعيفة أو عند بلوغ حد النموذج السريع).
   - `RATE_PER_MIN` (اختياري، الحد لكل جهاز، الافتراضي 30 طلبا في الدقيقة).
   - `ACCESS_CODE` (اختياري، رمز يدخله المستخدم من ⋮ لتقييد الاستخدام).
3. اضغط Redeploy ثم افتح الرابط من الجوال عبر HTTPS (الكاميرا المباشرة تتطلب HTTPS).

## ملاحظات
- المفتاح يبقى في الخادم فقط. الصفحة تستدعي `/api/scan` ولا ترى المفتاح.
- الطبقة المجانية في Gemini لها حد يومي وحد في الدقيقة مشتركان بين كل المستخدمين، فقد يتوقف الموقع مؤقتا عند الازدحام.
- الكاميرا تعمل مباشرة بلا التقاط صور: ثبات الصورة يقرأ الاسم والفئة (وتاريخ الانتهاء إن فُعّل) بطلب واحد، والباركود يُقرأ محليا بلا تكلفة. النقر على الإطار يضبط التركيز ويقرأ فورا.
- البيانات في متصفح الجهاز (localStorage للأصناف و IndexedDB للصور).
- ملف التصدير بصيغة `pharmora-items` الإصدار 1.

## فحص سريع للمفتاح والنماذج
افتح في المتصفح: `https://رابط-موقعك/api/scan?test=1`
- يعرض إن كان المفتاح مضبوطا، ونوعه، ونتيجة تجربة النموذج السريع والقوي.
- `status: 403` تعني مفتاحا غير صالح أو غير مفعّل، و`404` اسم نموذج غير متاح، و`429` بلوغ الحد المجاني.
- ملف `vercel.json` يضع الدالة في منطقة فرانكفورت (fra1) لتقليل زمن الاستجابة.
